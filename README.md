# Nail Studio

React + TypeScript + Three.js 美甲编辑器。画稿以十个独立指甲保存，浏览器本地运行，无需后端服务。

## 启动

```sh
npm ci
npm run dev
```

`npm run build` 执行 TypeScript 检查并生成 `dist`；`npm run preview` 预览构建产物。

## 使用

- 点击底部指甲缩略图选择编辑对象。甲型和长度对十指生效，底胶与图层默认只修改当前指甲。
- 法式：设置颜色、覆盖比例、微笑线弧度后添加图层；选中法式层可继续调节，也可用素材库图片填充。
- 波点：在 2D 画布点击或拖动绘制，或生成均匀波点。大小、颜色会更新选中的波点图层，间距用于后续绘制。
- 橡皮擦：先选择图层，再拖动擦除；只影响该图层，不破坏下方图层或底胶。
- 饰品、上传图片：点击素材添加图层，选择图层后在画布拖动移动，使用属性面板缩放、旋转或精确定位。越过甲面轮廓的区域自动隐藏。
- 图层支持显示、隐藏、排序、复制和删除。可将底胶或完整画稿复制到十指。
- 每次笔画或拖动计为一次撤销操作；支持 Cmd/Ctrl Z、Cmd/Ctrl Shift Z。
- 3D 预览平铺两排十指，拖动旋转、滚轮缩放、点击选指、双击重置视角。
- 设计自动保存到当前浏览器的 localStorage。保存项目文件导出可再次打开的 JSON（包括上传图片）；PNG 导出当前指甲的透明背景画稿。

## 2D 与 3D 如何保持一致

`src/model.ts` 加载 `public/甲型/<甲型>/<长度>/<名称><手指>.stl`。每个模型保留实际宽高，统一转换为甲根在上、甲尖在下、正面沿 +Z 的坐标系：原始 X/Z 平面正交投影为画布平面。

轮廓不是预设曲线，也不是凸包。程序投影 STL 的全部三角面，按同一绕序填充其并集，生成 512 像素宽的透明遮罩；高度按模型比例计算。纹理 UV 与该投影使用相同坐标，Canvas 顶部对应 UV 的 V=1。

`src/design.ts` 是共用画稿合成器：底胶 → 有序图层 → 每层擦除遮罩 → STL 轮廓裁切。2D 展示和 3D CanvasTexture 使用同一张合成画布，模型灯光仅在 3D 中叠加。切换甲型、长度时，图层使用相对坐标重新投影，不丢失画稿。

`src/useEditor.ts` 管理撤销历史、本地保存、模型加载取消和画稿缓存。`src/assets.json` 收录现有 198 张图片；新增图片后应更新该目录索引。

## 加载性能

- 切换甲型或长度时先读取当前选中的手指，当前 2D 画布可用后再按顺序补齐其他四指；3D 页面显示 `N / 5` 进度，不再等待五个文件全部完成后才渲染。
- STL 二进制解析放入 `src/stl.worker.ts`，不会长时间阻塞 React 主线程。切换或快速选择时旧请求会通过 `AbortController` 取消，已完成的模型会释放几何内存。
- 文件内容使用浏览器 Cache API 持久缓存最近 15 个 STL，内存保留最近 8 个；同一甲型和长度再次打开时不重复下载。缓存名称为 `nail-studio-stl-v1`，发布新的 STL 资源时请递增版本名。
- 正交遮罩由 512 像素宽降为 384 像素宽，作为 2D 编辑和 3D CanvasTexture 的共享纹理；不会改变 STL 几何精度。

- 当前饰品资源为图片，因此包括“立体饰品素材”在内均以贴图方式贴到曲面，不生成独立实体饰品网格。
- 左右手分别保存画稿，但复用同一套五指 STL。现有素材没有尖形短款，界面禁用该组合。
- 自动保存属于单机浏览器存储，没有账号、云端同步或服务器数据库。大图片达到存储额度时会显示失败提示，请导出 JSON 备份。
- STL 素材约 1 GB，首次加载某个甲型需下载五个文件。2D 轮廓是栅格正交投影，精度取决于 512 像素的遮罩宽度。
- 需要支持 Canvas 2D 的现代浏览器；3D 预览还需要 WebGL。没有 WebGL 时仍可使用 2D 编辑。
